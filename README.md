# TwinLife

Aplicativo para casais desenvolvido em Flutter.

## Primeira etapa

A primeira versão é um protótipo navegável com a identidade visual escolhida:

- Ivory `#FAF7F1`
- Sand `#E7D8C4`
- Mocha `#A78B7F`
- Terracotta `#C96F56`
- Burgundy `#7A1E2D`
- Soft Gold `#D4B483`

Tipografia: Cormorant Garamond + Plus Jakarta Sans + Caveat.

## Rodar localmente

```bash
flutter pub get
flutter run -d chrome
```

## Preview Web

Cada push na `main` executa `flutter analyze`, compila o Flutter Web e prepara o deploy pelo GitHub Pages.

No GitHub, configure uma vez em **Settings > Pages > Build and deployment > Source: GitHub Actions**.
